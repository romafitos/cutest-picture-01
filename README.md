# cutest-picture-01

Make the cutest picture. Entry program `main.py` (Python 3.13, stdlib
only) copies `cute.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`, verifying
the copy byte for byte.

The picture: a fluffy 3D-rendered baby sea otter pup with huge
sparkling eyes and a tiny pink bow, cuddling a chubby yellow duckling
cheek to cheek on a soft pastel background — 1024x683 JPEG, 117,596
bytes, within the 1 MiB / 1024x1024 gate.
